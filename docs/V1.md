# Aurat V1 runtime

## Promise

Point an OpenAI-compatible application at Aurat, record a real provider interaction once, and replay it deterministically in development or CI without contacting the provider again.

## Modes

- `live`: transparent proxy; no recording is persisted.
- `record`: proxy live traffic and append a recording to `.aurat/recordings.jsonl`.
- `replay`: never call the upstream provider; return the newest recording matching the request fingerprint.

## Matching

A V1 fingerprint contains the HTTP method, request path/query, and canonical request body. JSON object keys are sorted so serialization order does not create false misses. `stream_options` is ignored because SDKs can add it without changing the semantic request.

Authorization headers are not part of the fingerprint.

## Recording format

New recordings use format version 2 and store response bytes as base64. This keeps JSON, SSE, and other response bodies byte-safe. Replay remains backward-compatible with version 1 recordings where `response.body` was plain UTF-8 text.

## Streaming

Record mode tees the provider stream: one branch is sent to the application while the other is persisted. Replay preserves the recorded event-stream bytes. V1 does not yet reproduce the provider's original inter-chunk timing.

## Authentication

By default Aurat forwards the incoming `Authorization` header. Set `AURAT_UPSTREAM_API_KEY` (or `OPENAI_API_KEY`) to override it when forwarding upstream. This lets CI use a dummy SDK key while record/live mode uses the real provider credential inside Aurat.

## Debugging

Responses expose:

- `x-aurat-mode`: current runtime mode;
- `x-aurat-replay`: `hit`, `miss`, or `bypass`;
- `x-aurat-fingerprint`: deterministic request fingerprint.

`aurat inspect` summarizes captured endpoints, models, and OpenAI-style tool calls from both JSON and event-stream responses.

## Not in V1 yet

- semantic/generalized replay;
- behavioral contract inference;
- tool/service virtualization;
- fault injection;
- provider/model drift canaries;
- OpenTelemetry/Langfuse/LangSmith trace import;
- original streaming timing simulation.
