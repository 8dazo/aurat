# Aurat brand assets

A sculptural ribbon A represents a recorded path returning through verification. Its pearlescent finish takes material inspiration from [Captor's mark](https://github.com/8dazo/captor/blob/main/apps/marketing/public/logo.png); the silhouette and composition are distinct. No Costar repository was found in the connected account when preparing this reference.

| Asset | Use |
| --- | --- |
| `aurat-mark.png` | Transparent standalone symbol, 1280 × 1280 |
| `readme-hero.png` | Dark README banner with wordmark and product promise |
| `replay-workflow.svg` | Editable diagram of the implemented replay boundaries |
| `regression-proof.svg` | Editable graphic containing actual demo output excerpts |

Palette: charcoal `#101416`, warm white `#f3f4f1`, muted sea-glass `#bbd6d1`, and peach `#e9b89f` for failures. The symbol uses ice-blue and ivory highlights. Keep clear space around the mark; do not recolor or distort the raster master. Use descriptive alternative text wherever a graphic is embedded.

## Artwork provenance

The logo and banner were produced with the built-in image-generation tool, using the reference only for materials. The technical SVGs are authored vectors with exact text; they do not depict a hosted dashboard or fabricate product results. The README follows common developer-project information hierarchy: identity, purpose, quickstart, proof, integration and scope.

Prompt set:

1. **Logo:** One premium brand symbol for Aurat, a developer tool that replays AI agent workflows to catch regressions. Borrow Captor's frosted pearlescent ceramic/glass finish, subtle ice-cyan and warm ivory reflections, soft studio light and sculptural simplicity. Do not reuse its flower/starburst/petal silhouette. A compact architectural A formed from a broad continuous rounded ribbon, an open triangular counter and a folded return at the lower right suggesting replay. Mostly frontal, restrained depth, balanced geometry. One isolated mark, transparent background, generous margin. No text, badge, floor, external shadow, neon, rainbow or particle effects.
2. **Banner:** Panoramic 3:1 GitHub README banner. Preserve the supplied Aurat symbol and its pearl finish on the right third. Near-black charcoal background, Swiss editorial layout, warm-white grotesk typography, large negative space and a fine vertical divider. Exact copy: “AURAT”; “Replay the run.”; “Catch the regression.”; “Deterministic testing for AI agents”; “RECORD / REPLAY / VERIFY”. No dashboards, robots, other-company logos or traction claims.

The proof visual uses selected output from the bundled ticket-agent demo and its `--duplicate` mutation. Timing, revision and additional diagnostics are omitted, as stated in the graphic. Update the graphic if CLI semantics change.
